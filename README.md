# Псевдоцвета — лабораторная по ЦОВС

Два инструмента для псевдоцветного кодирования яркости: интерактивная страница
в браузере и пакетный скрипт на Python.

**Открыть страницу в браузере:** https://bogggare5671.github.io/pseudocolor-lab/ — ничего скачивать не нужно.

## `pseudocolor_lab.html`

Открывается двойным кликом, ничего ставить не нужно — весь код в одном файле,
без внешних библиотек.

- **Профили R, G, B по отсчётам.** Кривая задаётся только изломами, между
  соседними точками всё считается линейно. Клик — поставить точку,
  перетаскивание — двигать, `alt` или двойной клик — удалить.
- **Диаграмма цветности CIE xy.** Показывает спектральный локус, треугольник
  выбранной системы и траекторию кодирования. Клик по диаграмме задаёт путь:
  ломаная равномерно раскладывается по текущему числу отсчётов и пишется
  сразу в три профиля. Правая кнопка убирает последнюю точку.
- **Системы:** sRGB/Rec.709, PAL/SECAM (EBU), NTSC 1953, SMPTE-C,
  Adobe RGB 1998, DCI-P3, Rec.2020 — со своими первичными цветами, белой
  точкой и гаммой.
- **Алгоритмы обхода:** спирально-треугольный, стигмаобразный, круговой,
  спиральный. Каждый даёт ровно столько точек, сколько задано отсчётов.
- **Проверка на реализуемость:** если траектория выходит за спектральный локус,
  страница считает, сколько уровней яркости физически не существует.
- **Изображение:** своё или тестовая таблица; рядом исходное и обработанное,
  под ними кадры «путь по первый отрезок, по второй и так далее».
- **Обмен данными:** `Сохранить json` пишет отсчёты, систему, гамму, путь по
  диаграмме и готовую таблицу 256×3; `Загрузить json` читает это обратно.

## `curve_paint.py`

То же кусочно-линейное кодирование, но пакетом и воспроизводимо — одной кнопкой:

```bash
python3 curve_paint.py
python3 curve_paint.py --image photo.jpg --curves curves_var1.json --mode tint --space ycbcr
python3 curve_paint.py --all-spaces
```

- `--mode lut` — аргументом кривой служит сам пиксель (цветокоррекция),
  `tint` — номер кадра, `gradient` — координата по ширине кадра.
- `--space srgb | linear | ycbcr | lab` — к каким трём каналам применяются кривые.
- Результат складывается в `out/`: кадры, контактный лист и график кривых.

Зависимости: `numpy`, `pillow`.

## `curves_var1.json`

Вариант 1: `n` — число отсчётов, `E`, `R`, `G`, `B` — только изломы,
промежуточные отсчёты достраиваются линейно.
